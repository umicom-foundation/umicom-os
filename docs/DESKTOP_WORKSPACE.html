Use the Umicom OS desktop workspace

The user-space desktop gives access to Framework's recoverable notes workspace and read-only System Centre. It runs within your current operating system.

Keep notes and checkpoints

  1. Launch the Umicom OS desktop shell.
  2. Choose Open persistent desktop workspace. The new window shows the workspace directory.
  3. Choose Open workspace to open storage. If storage is unavailable, the window reports the failure; it does not silently substitute a temporary memory store.
  4. Create or edit a note. Changes remain in the draft until you choose Save checkpoint.
  5. To inspect an earlier saved state, enter a retained checkpoint number and choose Preview checkpoint. Follow the review controls before restoring it.

Restoring a checkpoint creates a new revision. It does not undo external file changes or application transactions. Keep your usual backups; the workspace retains a bounded history.

Inspect system information

  1. Choose Open System Centre.
  2. Choose Refresh to request a new snapshot.
  3. Read the overview, processes, network and boot observations. Refresh again when you need newer information.
Opening the desktop does not automatically open storage or collect a system snapshot. These tools do not install an operating system, alter boot settings or replace your current desktop session.

If something is unavailable

Keep the error message and check that the Framework GTK components and SQLite adapter were included in your build. If another process owns the workspace, close that workspace normally before reopening it. Do not delete lock files to bypass a running owner.
