# Umicom native audio host tools

This CMake entry composes `framework/examples/creative_audio` and its real canonical dependencies. It does not build a kernel, boot a guest, mount a disk or start an audio device. Use `UMICOM_OS_FRAMEWORK_SOURCE` for the reviewed Framework checkout. Follow `framework/docs/learning/CREATIVE_AUDIO.html` for the beginner exercise. Existing OS profiles and image tools are unchanged.
